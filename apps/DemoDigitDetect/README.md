## DemoDigitDetect

This application is a modified version of the DemoCamera application.
It allows you to take a picture, and then scans the picture for a
digit between 0 and 9 which it attempts to classify using a neural
network.

It has been produced with the support of [NLnet](https://nlnet.nl/).
